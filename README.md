# 🧮 BMI Calculator

A simple and interactive **BMI (Body Mass Index) Calculator** built with HTML, CSS, and JavaScript. This project allows users to calculate their BMI based on their height and weight and displays their BMI category along with a personalized message.

## 🚀 Live Demo

🔗 **[View Live Demo](https://elyardev.github.io/BMI-Calculator/)**

## ✨ Features

- 🧍 Calculate BMI using height and weight
- 📊 Display the calculated BMI value
- ⚖️ Categorize results into different BMI ranges
- 💬 Show personalized messages based on the result
- 🚨 Validate user input to prevent invalid calculations
- 🎨 Clean and modern user interface
- 📱 Responsive design (depending on screen size and styling)

## 🛠️ Built With

- **HTML5** — Page structure and semantic elements
- **CSS3** — Styling and visual design
- **JavaScript (Vanilla JS)** — BMI calculations, input validation, and dynamic DOM manipulation

## 📋 BMI Categories

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal weight |
| 25 – 29.9 | Overweight |
| 30 and above | Obesity |

*These categories are general adult BMI classifications and are not a medical diagnosis.*

## ⚙️ How It Works

1. Enter your height in centimeters.
2. Enter your weight in kilograms.
3. Click the **Calculate BMI** button.
4. View your BMI value, weight category, and corresponding message.

The BMI is calculated using the following formula:

`BMI = Weight (kg) / Height (m)²`
